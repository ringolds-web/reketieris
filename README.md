# Reketieris

A third-person shooter set in a Riga courtyard in 1993, built in Unity for the browser. Play: https://ringolds-web.github.io/reketieris/

This repository holds only the built game. The 3D models are from Sketchfab under CC BY 4.0, and every author is
credited on the game page ("Modeļu autori").
