# Reketieris

A third-person shooter set in a Riga courtyard in 1993, built in Unity for the browser.

**Play it here: https://reketieris.berzinsrinalds.workers.dev** (hosted on Cloudflare, with the leaderboard).

This repository holds an older built copy and is no longer published. The 3D models are from Sketchfab under CC BY 4.0;
every author is credited on the game page ("Modeļu autori").
